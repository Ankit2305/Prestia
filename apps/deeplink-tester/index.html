Deeplink Tester

Test deep links on a real Android device, in seconds.

Features

What it does

Open any link

Paste a custom-scheme or https link and open it with one tap.

History

Every link you open is saved with the time it was last triggered, newest first.

Run it again

Open any link from your history again with a single tap.

Copy

Copy a saved link to the clipboard to share it or use it elsewhere.

Tidy up

Delete links you no longer need.

Clear errors

If no app on the phone can handle a link, the app tells you so.
